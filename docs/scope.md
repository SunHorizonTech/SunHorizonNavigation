# 范围与依赖

本分支采用 Apache-2.0，仅包含主仓精简源码。保留的 C++/CUDA 实现、消息接口和安全逻辑与主仓基准一致。
软件许可不改变外部库、SDK 或厂家资产的许可。

## 未包含的内容

- NavigationDependencies 的源码、二开补丁、二进制及私有子模块配置。
- 现场配置、模型、地图、录包、实测 fixture、内部文档和远程部署脚本。
- 备用 AMCL、GLIM、RTAB-Map、视觉定位路线及后端聚合包。
- 旧多后端/LiDAR/Nav2 组合启动、模拟与影子试验包、现场运动验收工具。

保留 LIVO、Nav2 集成和最终速度监督器，未移除停机/锁停条件，未提供绕开缺失依赖的空实现。
保留包内的适配启动代码及测试仍可能引用缺失配置或历史测试输入；它们不是可直接运行的部署入口。

## 外部依赖边界

融合 runtime 需要 FAST-LIVO、Nav2、雷达 SDK 的二开 API；NDT CUDA 和速度命令证据头文件也有私有接口依赖。
相机/平台适配需要相应厂家 SDK/消息接口。公开上游版本不保证 ABI/API 兼容。
ROS、PCL、OpenSSL、Qt/RViz 等外部组件遵循各自许可。
本仓的 Apache-2.0 不对这些外部组件重新授权。

## 验证范围

根目录 CMake 只构建离线测试子集；macOS 本地 12 组测试通过。
Linux CI 工作流尚未远程执行；完整 ROS 2、ARM、硬件与实际运动未验证。
源码保留 /data/navigation 默认路径、接口命名和安全绑定检查，不附带这些路径所指的数据。
